# Genre Atlas · EN pocket explorer

검색한 장르 하나에서 출발해 클릭으로 연결을 펼치는 로컬 음악 지도. EN은 장르명·샘플·출처와 원본 지도 좌표의 기반이고, 포켓 관찰은 별도의 자료다.

인수인계와 다음 작업은 [HANDOFF.md](HANDOFF.md), 작업 원칙은 [AGENTS.md](AGENTS.md)를 먼저 참고한다. 단계별 화면은 저장소 루트의 PNG에 보존되어 있다.

## 실행

```sh
python3 -m http.server 8891 --bind 127.0.0.1
```

http://127.0.0.1:8891/app/ 에 접속한다. 외부 라이브러리·계정·빌드 도구가 필요 없다.

## 탐색

- 초기 지도는 비어 있다. 검색 결과를 선택하면 첫 노드 하나를 놓는다.
- 노드 클릭 또는 연결 펼치기로 근거 관계·예시를 추가한다. EN 근접 후보는 기본 꺼짐이며 켰을 때만 6개씩, 최대 48개를 순차 탐색한다.
- EN 근접 후보는 이름 기반 탐색 계열을 공유하는 장르 중 원본 좌표 거리 순서다. 점선은 후보이며 검증된 계보·하위 분류·포켓 유사도 관계가 아니다. 관계 탭에서 연결의 종류와 설명을 확인한다.
- 카메라는 650ms 동안 부드럽게 이동한다. 새 노드는 주변에서 나타나 힘 기반 배치로 펼쳐지고 기존 노드는 유지한다. 확대·축소 버튼도 보간 이동한다.
- 움직임 끄기 및 시스템 reduced-motion 설정을 따른다. 드래그와 휠 입력은 진행 중인 카메라 이동을 취소한다.
- 대분류는 메타데이터로만 사용한다. 같은 이름의 대분류·장르를 중복 노드로 만들지 않는다.
- 노드 120개까지 펼친다. 새 탐색은 화면만 비우며 저장한 설명·관계는 보존한다. 검색은 새 첫 노드에서 다시 시작한다.

## 포켓

기본 상세는 리듬·베이스다. City Pop, Neo Soul, Funk, House의 정량 창작 패턴에는 코드·보이싱·베이스 도수·길이·쉼과 포켓 설명 및 합성 재생이 있다. 킥·베이스만 듣기 옵션은 재생 시작 시 적용한다. 실제 곡 채보 또는 미세 타이밍 분석으로 간주하지 않는다.

House, Rock, Reggae, Dancehall에는 대표 곡과 문헌 근거 카드가 추가되어 있다. 문헌에서 확인된 특징과 미채보 항목을 분리한다. 출처는 앱 카드와 app/pocket-studies.js에 보존한다. 대표 장르부터 실제 곡 근거를 확인하며 순차 확장하는 방향이다. 나머지 장르에 분석을 자동 전파하지 않는다.

포켓 관찰 기록은 곡·구간, BPM, 킥과 베이스의 결합·엇갈림, 음 길이·쉼, 타이밍과 출처를 기록할 수 있다. 사용자 내용·관계·상태·후보는 해당 주소의 localStorage에 저장된다. JSON 내보내기·병합 불러오기 제공. 포트를 바꾸면 저장 영역이 달라진다.

## 데이터와 로딩

EN 원본 6,291개, JSON 1,893,655 bytes (약 1.89MB). 목록은 초기에 모두 읽고 검색 색인을 만들지만 화면 노드는 요청할 때만 생성한다. 근접 후보도 클릭 시 계산·캐시한다. 앱 상단에서 응답·JSON 처리·색인 준비의 실제 시간을 표시한다.

2026-10-07 로컬 IAB에서 47ms, 34ms 측정. 앱 데이터 요청 시작부터 검색 준비까지이며 브라우저 실행·HTML 전체 첫 화면 시간은 포함하지 않는다. 인터넷 배포·기기·캐시에 따라 달라진다. 전체 노드 동시 그리기 성능을 측정한 결과가 아니다.

## 다른 기능과 제한

- 설명·관계와 근거, 구식/Hot 독립 설정. 구식은 무채색, Hot은 반지름 6.5 → 9로 확대한다. 계열 색은 일정하며 미설정은 평가 전이다.
- 수동 새 장르 후보 관리와 검토 간격(1/3/6개월). 자동 웹 수집·예약 실행은 미연결.
- 사용자 관계는 관련/분류 갈래/영향/혼합/화성/리듬·베이스 비교를 구분한다. legacy 하위→부모/영향→원천 저장값도 호환한다. 복수 부모와 순환을 허용하며 엄밀한 계층 검증은 미구현.
- Metal 일부 계층과 네 장르의 비교 연결은 프로젝트 예시다. 예시 트리는 기본 화면에서 숨겨져 있다.
- 기존 「장르지도」의 검색 시작·클릭 확장 개념을 유지한 독립 구현이다.

## 검증

```sh
node --check app/app.js
node --test tests/navigation.test.cjs
```

카메라 중간 위치 보간과 원본 좌표 기반 후보 정렬·자기 노드 제외를 검증한다. 브라우저에서 초기 전체 목록 준비, 대표 장르 검색·연결 펼치기·자료 표시를 확인했다.

## 노드 표시

빈 원은 EN 기초정보만 있는 상태, 채운 원은 설명·곡 근거·포켓 자료가 있는 상태, 내부 점은 창작 포켓 예시 또는 사용자 포켓 기록이 있는 상태다. 자료의 존재를 나타내며 검증·정확성 등급은 아니다. 선택한 노드만 바깥 링을 갖는다. 구식과 Hot은 동시에 설정할 수 있다. 기존 v1 old/hot/allround 저장값은 그대로 읽으며 변경할 때 독립 플래그로 저장한다. 상태는 자동 유행 판정이 아니라 사용자 설정이다.

확장 시 주변 노드가 가까우면 선택 노드를 빈 방향으로 약 230 단위 부드럽게 이동하고, 새 노드는 180~320 단위의 여유 공간에 배치한다. 연결 간격을 210으로 늘리고 이름 영역이 겹치면 반발력을 적용해 겹침을 줄인다. 항상 겹치지 않는 엄밀한 배치 보장은 아니다.

선택·확장·현재 노드 중심·화면 크기 변경은 현재 줌 배율을 유지한다. 화면에 모든 이웃을 넣으려는 자동 축소는 제거했다. 확대/축소와 휠, 명시적인 1:1 버튼으로만 배율을 조절한다. 새 검색/새 탐색은 배율 1에서 시작한다.

## Pop의 첫 근거 관계 구간

app/pop-relations.js에 8개 관계를 기록했다. Pop → Dance Pop/Synthpop/Bubblegum Pop은 문헌의 스타일 설명을 바탕으로 프로젝트가 구성한 분류 갈래다. 이를 단일 역사적 조상·후손으로 해석하지 않는다. Pop + Rock → Pop Rock은 혼합, Disco/Synthpop → Dance Pop과 New Wave → Synthpop은 영향 관계다. 각 관계의 설명과 백과사전 출처는 관계 탭에서 확인한다. 이 구간은 전체 Pop 계보의 완성본이 아니다.

갈래는 실선 화살표, 영향은 파선 화살표, 혼합은 보라색 실선 화살표로 표시한다. 기존 v1 하위→부모와 영향받음→원천 기록은 저장 방향을 유지한 채 그림에서 반전해 부모/원천 → 하위/영향받은 장르로 보여준다. 새 사용자 관계에는 갈래·영향·혼합 종류를 제공한다. EN 후보는 기본 꺼짐이며 체크박스로 켜면 근접 연결을 추가한다. 네 장르의 창작 포켓 비교 연결은 기본 확장 경로에서 제외했다.

## 저장소 백업 범위

코드, EN 데이터, 설계·인수인계 문서, 화면 PNG와 output/의 MIDI를 포함한다. 브라우저 localStorage의 개인 편집값은 Git에 포함되지 않는다. 앱에서 내보내기한 JSON을 별도 보관하고 다른 환경에서 불러오기한다. 현재 화면의 펼친 노드·배치는 메모리에만 존재한다.
